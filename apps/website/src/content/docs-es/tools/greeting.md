**Greeting** es una herramienta de demostración y prueba de humo. Existe para que
puedas confirmar que un servidor MCP recién creado está conectado y respondiendo,
antes de agregar algo real — no tiene efectos secundarios.

## Herramienta

- **Greeting** — devuelve un saludo con plantilla para un nombre dado, en inglés o
  en español. Está pensada solo para pruebas (por ejemplo, pedirle a tu cliente que
  "pruebe la herramienta de saludo"); en una conversación normal el asistente
  simplemente responde directo en lugar de llamarla.

Una vez que confirmes que el servidor funciona, sigue con una integración real como
[Gmail](/es/docs/tools/gmail), [Slack](/es/docs/tools/slack) o
[Búsqueda web](/es/docs/tools/web-search).
